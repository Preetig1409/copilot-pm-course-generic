## Segment 4: "Does It Work at Accenture?" — Team Saravum Lead (2:00)

**Role:** Enterprise Realism — share real testing findings

**Screen:** Optional screen share (can also narrate with camera)

### Script (0:00–0:30) — Frame the enterprise angle

> "We didn't test this in a sandbox. We tested it inside real Accenture infrastructure — with all the constraints your PMs deal with every day."

### Script (0:30–1:30) — Share 3 concrete findings

> "Here's what we found:
>
> **What worked:** File uploads, Teams integration, and SharePoint discovery all worked as the course describes. PMs could follow along in their real M365 environment.
>
> **What surprised us:** Sensitivity labels. When documents have certain classification labels, Copilot's behavior changes — some prompts get blocked or return partial results. We documented those edge cases so PMs know what to expect.
>
> **What we fixed:** Keyboard shortcuts that varied between browser and desktop app. Enterprise-specific quirks in how Copilot reads SharePoint sites. Real issues caught by real practitioners — and now addressed in the course content."

### Script (1:30–1:45) — Land the point

> "This course was battle-tested against real Accenture infrastructure. When your PMs use it, it'll work."

## Key Rules for All Presenters

1. **Pre-load your screen.** Have the app open to your specific module BEFORE the call. No live navigation to find things.
2. **No live Copilot demos.** Don't actually run Copilot live — it's unreliable on calls. Show the course content and narrate what happened during testing.
3. **Use the transition lines.** The handoff questions ("But does it actually teach you?") create a story arc. Don't skip them.
4. **Stay within 2 minutes.** If you're running long, cut your middle section — always land your key message and transition.
5. **Rehearse once.** One 15-minute dry run will cut 3 minutes off the live version and eliminate awkward transitions.
